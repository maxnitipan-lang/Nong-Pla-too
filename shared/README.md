# shared — ใช้ร่วมกันทั้งหน้าเว็บและเซิร์ฟเวอร์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `campus.ts` | ข้อมูลวิทยาลัย: อาคาร 22 จุด พิกัด ชั้น ห้อง สาขา ข่าวตัวอย่าง และชนิดข้อมูล |
| `walkNetwork.ts` | คำนวณเส้นทางเดินจริงตามทางเท้า และสร้างคำบอกทาง "เลี้ยวซ้าย/ขวา" |
| `data/campusWalkNetwork.json` | เส้นทางเดินตั้งต้นในวิทยาลัย (แก้ได้ที่ `/admin/walkways`) |
| `roles.ts` | สิทธิ์ admin / editor / viewer |
| `adminSchemas.ts` | กฎตรวจข้อมูลที่กรอกในหน้า admin |
| `myMaps.ts` | อ่านไฟล์ Google My Maps |
| `ai.ts` | อ่านคำตอบจากแชตบอต |
| `const.ts`, `types.ts`, `_core/` | ค่าคงที่และชนิดข้อมูลพื้นฐาน |
