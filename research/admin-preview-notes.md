# Admin preview verification

ตรวจภาพหน้า `/admin` หลังเพิ่ม dashboard-with-collapsible-sidebar component.

ผลที่เห็นบน desktop 1280x720:
- Sidebar แสดงเมนู ภาพรวมระบบ, อาคารและตำแหน่ง, ข่าวสารวิทยาลัย
- แสดง shortcut ดูหน้า PLato Guide และตั้งค่าเนื้อหา
- แสดงปุ่มย่อเมนูและออกจากระบบ
- Dashboard แสดงจำนวน 6 อาคาร และ 3 ข่าวสารจากข้อมูลตั้งต้น
- Layout มี hero content control และ cards สรุปจำนวนรายการ
- TypeScript และ production build ผ่านก่อนการตรวจภาพ
