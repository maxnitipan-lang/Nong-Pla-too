# scripts — คำสั่งช่วยที่รันด้วยมือ

| ไฟล์ | คำสั่ง | ใช้ทำอะไร |
| --- | --- | --- |
| `syncNews.ts` | `npm run news:sync` | ดึงข่าวจากเว็บวิทยาลัยลงฐานข้อมูล จากเครื่องนี้ (ใช้เมื่อเว็บวิทยาลัยบล็อกเซิร์ฟเวอร์ Render) |
| `buildWalkNetworkFromOsm.ts` | `npx tsx scripts/buildWalkNetworkFromOsm.ts` | สร้างเส้นทางเดินตั้งต้นจากข้อมูล OpenStreetMap ใน `data/` |
