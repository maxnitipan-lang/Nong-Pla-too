# campus — ข้อมูลและบริการของวิทยาลัย

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `walkingRoute.ts` | ขอเส้นทางเดินนอกวิทยาลัยจาก OpenRouteService (ใช้เมื่อผู้ใช้อยู่ข้างนอก) |
| `newsScraper.ts` | ดึงข่าวจากเว็บวิทยาลัยอัตโนมัติทุก 6 ชั่วโมง |
| `seed.ts` | ใส่ข้อมูลตั้งต้นลงฐานข้อมูลใหม่ (`npm run db:seed`) |

การคำนวณเส้นทางเดินในวิทยาลัยอยู่ที่ `shared/walkNetwork.ts`
