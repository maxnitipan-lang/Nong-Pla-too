# server — ระบบหลังบ้าน (Express + tRPC)

| โฟลเดอร์ / ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `routers.ts` | รวม API ทั้งหมดที่หน้าเว็บเรียกใช้ (ชื่อเดียวกับแอปเก่า) |
| `db.ts` | คำสั่งอ่าน/เขียนฐานข้อมูล (อาคาร, ข่าว, ผู้ใช้, เส้นทางเดิน, ตั้งค่า) |
| `assistant/` | แชตบอตและเสียง |
| `campus/` | เส้นทาง ข่าว และข้อมูลตั้งต้นของวิทยาลัย |
| `admin/` | API ของหน้าเจ้าหน้าที่ |
| `_core/` | ระบบพื้นฐาน: เปิดเซิร์ฟเวอร์, ล็อกอิน, cookie, สิทธิ์ |
| `tests/` | ชุดทดสอบ (`npm test`) |
| `storage.ts` | อัปโหลดไฟล์ผ่านระบบของ Manus (ยังไม่ได้ใช้) |
