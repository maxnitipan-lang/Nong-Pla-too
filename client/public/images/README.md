# images — รูปที่ใช้ในแอป

| โฟลเดอร์ | ใส่รูปอะไร | ไปผูกชื่อที่ไหน |
| --- | --- | --- |
| `buildings/` | รูปบนหมุดอาคารในแผนที่ ตั้งชื่อตามรหัสอาคาร เช่น `mech-auto.png` | `BUILDING_MARKER_IMAGES` ใน `client/src/config/kioskAssets.ts` |
| `departments/` | โลโก้สาขาวิชา | `DEPARTMENT_LOGOS_BY_NAME` ในไฟล์เดียวกัน |
| `kiosk/` | รูปตัวละครน้องปลาทู และภาพพื้นหลังตู้ | `KIOSK_ASSETS` ในไฟล์เดียวกัน |

แนะนำรูปสี่เหลี่ยมจัตุรัส ประมาณ 256×256 px เพื่อให้โหลดเร็ว
