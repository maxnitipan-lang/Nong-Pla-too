# lib — ฟังก์ชันช่วย

| ไฟล์             | ใช้ทำอะไร                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------- |
| `voice.ts`       | ฟังเสียงพูด (แปลงเป็นข้อความ) และพูดตอบ (เสียง AI หรือเสียงเครื่อง) รองรับ iPhone/Android |
| `directions.ts`  | คำนวณระยะทาง, อ่าน GPS, จัดรูปแบบ "120 ม. · 2 นาที", ลิงก์ Google Maps                    |
| `offlineData.ts` | เก็บข้อมูลอาคาร/ข่าวไว้ในเครื่อง ใช้ได้แม้อินเทอร์เน็ตหลุด                                |
| `trpc.ts`        | ตัวเชื่อมเรียก API ของเซิร์ฟเวอร์                                                         |
| `utils.ts`       | รวม class CSS                                                                             |
| `*.test.ts`      | ชุดทดสอบ                                                                                  |
