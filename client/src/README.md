# client/src — โค้ดหน้าเว็บ

| โฟลเดอร์ / ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `App.tsx` | กำหนดว่าแต่ละ URL เปิดหน้าไหน (`/` ตู้, `/app` มือถือ, `/admin` เจ้าหน้าที่) |
| `main.tsx` | จุดเริ่มของแอป: เชื่อม API, ลงทะเบียน service worker, ปลุกเซิร์ฟเวอร์ทุก 10 นาที |
| `index.css` | สี ฟอนต์ และธีมสว่าง/มืด |
| `pages/` | หน้าจอแต่ละหน้า |
| `components/` | ชิ้นส่วนที่หลายหน้าใช้ร่วมกัน (แผนที่, แชตบอต, QR) |
| `hooks/` | ตรรกะที่ใช้ซ้ำ เช่น ระบบนำทาง, จับเวลาว่างของตู้ |
| `lib/` | ฟังก์ชันช่วย: เสียง, ระยะทาง/GPS, การเชื่อม API |
| `config/` | ตั้งค่ารูปภาพทั้งหมด (ตัวละคร, โลโก้สาขา, รูปบนหมุด) |
| `contexts/` | ธีมสว่าง/มืด |
| `_core/` | ระบบล็อกอินพื้นฐานจาก template (ไม่ต้องแก้) |
| `const.ts` | ค่าคงที่ของระบบล็อกอิน |
