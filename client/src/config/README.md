# config — ตั้งค่าที่แก้บ่อย

`kioskAssets.ts` คือที่เดียวที่ต้องแก้เมื่อเปลี่ยนรูป

| ค่า | ใช้กับ |
| --- | --- |
| `KIOSK_ASSETS` | รูปตัวละครน้องปลาทู และพื้นหลังตู้ |
| `DEPARTMENT_LOGOS_BY_NAME` | โลโก้สาขา (ใส่คำในชื่อสาขา เช่น `"ช่างยนต์"`) |
| `BUILDING_MARKER_IMAGES` | รูปบนหมุดอาคาร (ใส่รหัสอาคาร เช่น `"mech-auto"`) |

ไฟล์รูปวางไว้ที่ `client/public/images/`
