# hooks — ตรรกะที่ใช้ซ้ำในหลายหน้า

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `useCampusNavigation.ts` | หัวใจของการนำทาง: หาเส้นทาง, ติดตาม GPS, บอกทางด้วยเสียง, คำนวณใหม่เมื่อเดินออกนอกเส้นทาง |
| `useIdle.ts` | จับเวลาว่าง เมื่อไม่มีใครแตะตู้ตามเวลาที่กำหนด จะรีเซ็ตกลับหน้าแรก |
| `useMobile.tsx` | ตรวจว่าเป็นจอมือถือไหม |
| `useComposition.ts`, `usePersistFn.ts` | ตัวช่วยของช่องพิมพ์ข้อความ (จาก template) |
