# รายการเช็กน้องปลาทู (AI + เสียง)

ใช้ทดสอบทุกครั้งก่อนนำขึ้นตู้จริง หรือหลังแก้ข้อมูลวิทยาลัย / คำสั่งของ AI

## 1. ทดสอบอัตโนมัติ (คำตอบ + ความเร็วเสียง)

ต้องมี `GEMINI_API_KEY` (ขึ้นต้นด้วย `AIza`) ในไฟล์ `.env` และเปิดเซิร์ฟเวอร์ไว้ (`pnpm dev`)

```bash
pnpm ai:test
```

ทดสอบเว็บจริง:

```bash
pnpm ai:test https://nong-pla-too.onrender.com
```

สคริปต์ถาม 57 คำถามใน 8 กลุ่ม แล้วเช็กว่าคำตอบมี/ไม่มีคำที่กำหนด เปิดเส้นทางถูกอาคาร และวัดเวลาเสียง 3 แบบ
ผลอยู่ที่ `scripts/ai-test-report.md` — เป้าหมาย: ผ่านทุกข้อ, AI ตอบเฉลี่ยไม่เกิน 3 วินาที

| กลุ่ม | สิ่งที่เช็ก |
|---|---|
| ทักทาย | คำตอบสำเร็จรูป, พิมพ์ภาษาไทยตอนแป้นเป็นอังกฤษ ("g[njv") |
| เส้นทาง | เปิดเส้นทางไปอาคารที่ถูกต้อง, ไม่เดาที่ตั้งห้องที่ไม่มีข้อมูล |
| สาขา | ชื่อหลักสูตรตามเอกสารวิทยาลัย, ปวช./ปวส., ปริญญาตรี, ไม่แบ่งสาขาตามเพศ |
| ข้อมูล | เบอร์โทร อีเมล ที่อยู่ ผู้บริหาร จำนวนนักเรียน ประวัติ — ไม่แต่งค่าเทอมหรือชื่อครู |
| ข่าว | ข่าวล่าสุดและประกาศ |
| นอกเรื่อง | ตอบสั้นเป็นกันเอง, ปฏิเสธการบ้าน/การเมือง/หวยอย่างสุภาพ, สายด่วน 1323, ไม่หลุดรหัสผ่าน |
| เสียง (โหมดพูด) | สั้นไม่เกิน ~260 ตัวอักษร, ไม่มี markdown |
| ความเร็วเสียง | คำทักทาย < 1.5 วิ (เตรียมไว้ล่วงหน้า), ประโยคใหม่ < 9–12 วิ |

## 2. เช็กด้วยมือบนตู้จริง

- [ ] เปิดด้วย **Microsoft Edge** → ตั้งค่าเสียงในแชตขึ้น "อัตโนมัติ — ใช้ Niwat/Premwadee … Natural"
- [ ] กดไมค์ ถาม "ไปงานทะเบียนยังไง" → ได้ยินเสียงภายใน ~2 วิ และแผนที่เปิดเส้นทาง
- [ ] ระหว่างพูด แท่งเสียงในปุ่มขยับ, แตะปุ่มแล้วหยุดพูดทันที
- [ ] เสียงไม่เปลี่ยนคนกลางคำตอบ และไม่อ่านคำสั่ง ("พูดด้วยน้ำเสียง…") ออกมา
- [ ] พูดในที่เสียงดัง (มีคนคุยข้าง ๆ) → ยังฟังคำถามถูก
- [ ] โหมดสนทนาต่อเนื่อง: ตอบจบแล้วฟังต่อเอง, เงียบ 2 รอบแล้วหยุด
- [ ] พิมพ์ด้วยแป้นภาษาอังกฤษ (เช่น "g[njv") → น้องปลาทูเข้าใจเป็นภาษาไทย
- [ ] ปุ่มใต้คำตอบ ("🎯 เริ่มเกมเลือกสาขา", "🗺️ เปิดแผนที่") พาไปหน้าที่ถูก
- [ ] ทิ้งตู้ไว้ 90 วินาที → กลับหน้าแรก, แชตถูกล้าง
- [ ] สแกน QR เส้นทางด้วยมือถือ → เปิดการนำทาง GPS บนมือถือ
